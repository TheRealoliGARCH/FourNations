# FourNations

## Empirical Validation, Simulation Testing, and Policy Roadmap

This repository implements the empirical validation, simulation testing, and policy roadmap for *A Unified Theory of Monetary-Political-Economic Equilibrium*.

### Initial programme

1. Historical validation of the four-nation hypothesis.
2. Phase-coherence crisis prediction testing.
3. Zero-IRP empirical testing.
4. Four-agent dynamic simulation.
5. Shock, entry, and constraint-ablation experiments.
6. Reproducible policy indicators and stress monitoring.

The programme is falsification-first: theoretical claims are retained only to the extent supported by reproducible empirical and computational evidence.
