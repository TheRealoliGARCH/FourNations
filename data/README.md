# Data

## Acquisition sequence

1. Register source.
2. Download or archive raw artifact.
3. Record provenance.
4. Run deterministic transformation.
5. Validate schema.
6. Generate processed dataset.

No empirical result should depend on manually edited processed observations.

## Initial datasets to construct

### Historical system dataset

Target period: 1648–2026.

Purpose: test the relationship between N_powers and systemic crisis within five years.

### Phase-coherence dataset

Purpose: construct national phase angles from explicitly selected macro-financial series and test predictive value of Q.

### Monetary dataset

Purpose: estimate the Zero-IRP relation.

Historical coverage may differ across datasets; the common 1648–2026 window is a theoretical target for the historical-system test, not an assumed coverage requirement for every monetary series.
