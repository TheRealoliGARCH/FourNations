# Documented Scenario Output Protocol

The executable scenario set is read directly from `data/raw/nuclear_onset_scenarios.csv` and combined with the six fixed nuclear onset records in `data/raw/nuclear_onsets_seed.csv`.

The four executable scenarios are:

- `baseline`
- `israel_late_1966`
- `india_overt_1998`
- `joint_documented`

For each scenario, the code writes the complete entity-year Genuine panel, annual comparison with baseline, and the exact years with nonzero Genuine-count deltas.

The output is reproducible and scenario labels preserve the underlying onset convention. No alternative date is generated by imputation.
